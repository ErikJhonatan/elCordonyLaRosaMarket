# El Cordón y la Rosa · Reportes de un market

Sitio académico con presentación de un market y enlaces a reportes comerciales de Power BI.

## Contenido

Página de presentación con navegación, galería y tarjetas que enlazan a reportes de Power BI. El código organiza la estructura en `index.html`, estilos en `CSS/`, comportamiento en `JS/` y recursos visuales en `IMG/` y `ASSETS/`.

## Uso y alcance

Sirve la carpeta como sitio estático. Los reportes dependen de enlaces externos; esta revisión no comprobó su disponibilidad ni sus datos. El repositorio contiene la web de presentación, no los modelos de datos de Power BI.

## Créditos

Proyecto de Ingeniería de Software II de la Universidad Privada San Juan Bautista. La página reconoce a Erik Jhonatan, Diego Alejandro y Daniel Alexander como desarrolladores.
